# מתקפת הזומבים

משחק הישרדות ואקשן 2D לדפדפן. עשרים מפות, גלים, זומבים מיוחדים, בוסים ומערכת שדרוגי נשק.

## הפעלה

פתחו את `index.html` בדפדפן, או הריצו שרת מקומי:

```bash
python3 -m http.server 8080
```

ואז היכנסו אל `http://localhost:8080`.

## שליטה

- `WASD` — תנועה
- עכבר — כיוון
- לחיצה שמאלית — ירי
- `R` — טעינה
- `1`–`9` / `0` — בחירת נשק שנאסף
- גלגלת העכבר — מעבר בין כל הנשקים

במכשירי מגע מופיעים ג'ויסטיק, כפתור ירי ופס נשקים בחלק העליון.

אחרי ניצחון על בוס מוצגים שלושה נשקים חדשים לבחירה במקום שדרוג. נשקים שכבר נאספו אינם יכולים להופיע שוב, והסיכוי לשלל נדיר עולה ככל שהארסנל גדל. השדרוגים הרגילים ממשיכים להשפיע על כל הנשקים.

כל מפה כוללת שלושה גלים ולאחריהם בוס. בתחילת מסע חדש בוחרים אקדח שירות, מחבט או קשת חלשה שיורה חץ נראה לעין פעם ב־2 שניות. החרב היא נשק תגרה כחול וזוהר בעוצמה דומה לרבולבר, והיא יכולה לקבל גם שדרוגי רעל וקרח. כשמחזיקים נשק תגרה, שדרוגים שאינם מתאימים לו אינם מוצגים.

בכל גל הזומבים מקבלים עוד 5% חיים ועוד 5% נזק. כל שדרוג מוגבל לשלוש דרגות, שדרוג הנזק מוסיף 10% בכל דרגה, ושדרוג חדירת הקליעים הוסר. הסנייפר שומר על טווח של כל המפה אך נעצר באויב הראשון.

בתחילת כל גל החיים והמגן מתמלאים. לפני הבוס הראשון אקדח השירות נוסף אוטומטית לארסנל ומצויד. במחשב כל הנשקים שנאספו מוצגים בפינה השמאלית התחתונה עם מספרי הקיצור; אפשר גם ללחוץ עליהם. הודעת החלפת נשק מופיעה בצד ולא במרכז הקרב.

קליע של זומבי יורק גורם תמיד 15 נזק, ללא תלות במפה. צלילי הנשקים נוצרים בשכבות Web Audio נפרדות של פיצוץ, הדף ורעש מתכתי, עם אופי שונה לנשקים כבדים, אוטומטיים, טסלה ולהביור.

## שמירה מקומית

בכניסה הראשונה המשחק מבקש שם שחקן ויוצר פרופיל פרטי בדפדפן. ההתקדמות נשמרת רק ביציאה: דרך "שמור וצא" במסך העצירה, בסגירת הלשונית או ברענון הדף. מוות אינו משנה את נקודת ההמשך האחרונה. השמירה כוללת את המפה והגל, הנשקים, השדרוגים, החיים והמגן. כפתור "מחק משתמש" בתפריט מוחק את הפרופיל ואת כל ההתקדמות מהמכשיר.

גלגל השיניים פותח את ההגדרות. אפשר לשנות שם שחקן, לעבור בכל רגע בין שליטת מחשב לשליטת טלפון, ולבחור עברית או אנגלית. כל ההעדפות נשמרות בפרופיל המקומי.
