—

Floating Ink שומר גרסה לפני שמתחילים לערוך, ועוד אחת כל חצי שעה של כתיבה. אפשר גם לשמור גרסה בעצמך.

איך מחברים את קלוד?
  1. מורידים את המחבר של Floating Ink: הורדת המחבר
  2. באפליקציית Claude שבמחשב: הגדרות ← Plugins (תוספים) ← Add ← Upload plugin, ובוחרים את הקובץ שירד.
  3. מסמנים כאן למעלה את התיבה. אם הדפדפן שואל אם לאפשר גישה לאפליקציות במחשב, מאשרים.
  4. פותחים שיחה עם קלוד וכותבים לו: תתחבר ל-Floating Ink. מכאן הוא עונה בחלונית הזאת.

כשהחיבור פתוח, קלוד יכול לקרוא ולשנות את המסמכים כאן, ומה שהוא קורא נשלח אליו כמו כל הודעה שכותבים לו. כל שינוי אפשר לבטל עם Ctrl+Z.
